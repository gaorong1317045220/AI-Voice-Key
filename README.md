# AI Voice Key

Windows desktop companion for the AI KEY voice input and computer remote.

Download the latest Windows package from the [Releases](https://github.com/gaorong1317045220/AI-Voice-Key/releases/latest) page. The package includes `AI Voice Key.exe`, the SenseVoice model, and Chinese installation instructions. It does not require a separate Python installation.

The firmware source and application documentation are maintained in the [AI Passport project](https://gitee.com/FoloToy/ai-passport).
